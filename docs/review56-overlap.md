# PR #56：相交部件的气动面积核查

对应 [评论 6863525621](https://github.com/Nigh/glider-3d/pull/56#issuecomment-6863525621)。比较基线为 `2d805f9`，修正后的物理版本为 `exposed-airframe-v24`。

确实存在重复计入：旧模型把完整座舱椭球与固定半个罩体分别求阻力，并让埋在座舱/机身内的翼段继续产生完整气动力。固定扣掉半个罩体不能代表它与座舱、翼面的实际交集。

## 修正方法

- 用共享座舱等效椭球、上半罩体、渲染同尺寸的锥形尾梁及机鼻建立实体包含判定。座舱、罩体和尾梁/机鼻互相埋入的表面不再计入；翼段也会遮掉机体内部的表面。
- 对剩余外露的座舱/罩体表面，压差项计算 `0.18 × ∫max(0, n·v_local)dA`，摩擦项计算 `0.004 × A_exposed × |v_local|`，再沿局部来流的反方向求力。安装点的转动来流、力矩及耗散继续参与真实积分。
- 翼段按上下截面在座舱/机身外的面积比例缩放升力、型阻、分离阻力、展向阻力、截面力矩与尾迹环量；智能混控的载荷导数使用相同比例。几何面积、质量、惯量、结构及水载荷仍使用原始实体。
- 机身原有 `0.07 m²` 是含阻力系数的等效面积代理，按尾梁/机鼻的外露投影与完整投影之比修正，不重新标定其系数。发动机外阻系数未修改。
- 外露缓存随翼段的形变、实时安装角、断裂归属改变而更新；复原、重置与 checkpoint 重建后由几何重新派生。脱离的翼片按自身外露翼面计算。

裁剪针对实际三维相交。前后分离的两个翼面即使在来流方向上投影重合，也仍有各自的载荷与已有尾迹耦合，不能直接删除后翼的气动力。

## 验证与边界

新增回归使用独立的 600×600 截面栅格核对座舱与罩体的轴向并集投影，数值积分误差小于 2.5%；同时覆盖翼根/翼尖、变形、脱离/复原、机身遮蔽、正反与斜向来流、转动耗散、实时安装角和 checkpoint 确定性。既有测试继续检查真实求力与遥测的分项闭合、力矩与能量账本，以及飞行/风洞同状态的一致性。

原尾迹夹具调整为两种主翼高度均高于座舱，以隔离尾迹效应；导轨夹具联合配平座舱位置和空速，自适应舵机保留原末秒精度与应力上限、将收敛窗口延长至 6 秒。

验证结果：完整单进程运行的 32 个文件、493 项断言全部通过（长时测试使用临时 `--testTimeout=30000`）。该次运行另有一条 Vitest worker `onTaskUpdate` 通信超时，退出码为 1；巡航文件的连续同步求解会阻塞事件循环。随后增加每例结束后让出事件循环，该文件 3 项独立重跑通过、退出码为 0。相关 Chromium 界面回归 2 项通过；`npm run check` 为 0 错误/0 警告，生产构建成功，仍有既有的大包提示。

这是有限采样的游戏工程模型：机体表面采用 24×48 数值积分，翼段采用 12×24×上下两面的覆盖采样，外露翼段仍沿用原作用点。它没有新增 CFD、前后分离机体的遮挡流场、翼片间尾迹或实测阻力标定；不能据此声称所有姿态的真实阻力都已精确预测。旧成绩与回放由物理版本检查隔离。
