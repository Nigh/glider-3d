# 本地飞行平衡实测

2026-10-30，通过运行中的 Vite 页面直接加载项目 `src/physics.ts` 与 `src/model.ts`，在 Chromium 执行六种预设。固定步长1/60 s、无风、零操纵，从平台入口静止助跑至接水；不是手工轨迹或原版数据。

## 当前模型

|---|---:|---:|---:|---:|

| 高展弦比型 | 145.63 | 17.10 | 12.08 | 9.99 |
| 高稳定型 | 118.74 | 14.27 | 13.08 | 9.98 |
| 灵敏操纵型 | 121.31 | 14.58 | 13.30 | 9.98 |
| 重心过后不稳定型 | 15.47 | 6.58 | 10.00 | 6.16 |
| 高翼载荷型 | 24.32 | 6.17 | 15.58 | 9.99 |

全部预设真实接水结束。逐步采样 `abs(potentialEnergy + kineticEnergy + dissipatedEnergy - initialEnergy) / initialEnergy`，六种运行中的最大相对误差为 `2.50e-13` 以下。耗散来自同一中点状态下的阻力及角阻尼功，不包含人为填入的积分误差。

当前起点高度由最低接触点决定，默认飞机重心初始高度为10.8254 m；平台顶面10 m，最低点净空0.05 m。各构型统一在出口达到10 m/s，但离台时重心高度随构型不同。因此能量槽使用每次离台时自己的机械能作为基准，不宣称所有构型初始总能量相同。

## 设计影响与配平

主翼面积、展弦比、主尾翼安装角、重心位置和尾翼力臂共同决定飞行表现。增加面积不保证航程单调增加：它同时改变质量、阻力、配平及离台高度。测试不再要求任意两种几何的航程必须相差指定米数。

主翼升力参考点为平均气动弦四分之一弦；全机中性点另外包含尾翼效率估算。正静稳定裕度不等于已经配平，应继续观察实际攻角、俯仰、失速和距离—高度曲线。

## 复现

`npm test -- tests/physics.test.ts` 覆盖起飞、六预设终止、A–H气动行为、重放、控制抖动及能量边界。在游戏内选择相同预设、不施加操纵，也可观察真实助跑、飞行仪表与结果。该记录替代旧的固定位置、5°初始俯仰模型数据，不与旧性能记录混用。
