# 《人力滑空機.sim》原版黑盒调查

## 调查范围与证据规则

- 调查日期：2026-10-30。
- 顶层页面：[https://swipla.co/g/250tdqhpwq](https://swipla.co/g/250tdqhpwq)。实际游戏 iframe：[https://asobi-games.whele-games.workers.dev/250tdqhpwq/index.html](https://asobi-games.whele-games.workers.dev/250tdqhpwq/index.html)。直接访问 iframe 地址会回到顶层游戏页。
- 方法：真实 Chromium 浏览器；点击页面现有按钮、修改页面现有 range 控件并触发 input、使用真实鼠标拖动画布。没有读取游戏源码、脚本内容、内部模拟状态或私有函数。
- **Observed**：本次浏览器界面、DOM 可见文字、原生 input 属性、实际操作后结果。
- **Inferred**：根据多项观测作出的解释，不作为原版实现事实。
- **Unknown**：未观测、操作未成功或无法由黑盒证据确定。未用估算值填补。
- 原始逐次文字记录：[evidence/observations.json](evidence/observations.json)。其中保留每次实验操作坐标、修改后界面文字、完整结果页，以及失败尝试。
- 每次正式实验先点击首页 `#bReset`，再进入对应设计页。没有先点击设计页的「ガイドどおり」，也没有点击组装自动配平。设计共享同一浏览器存储；实验逐个执行，没有并发改原版机体。
- 标准实验不操纵飞控。像素坐标基于全屏 1365×681 画面；坐标不是物理参数。改形会同时改变面积、展弦比、后掠、质量或力臂，不宣称单一物理变量的严格因果隔离。

## 1. 初始流程与界面

**Observed**：标题「人力滑空機.sim」。说明为从高度 10m 的台上起飞，先试预制机，再自行设计。首页有「飛ぶ ▶」「設計する」「最初の機体に戻す」，并显示自己最佳距离。

- `#bFly`：首页直接飞行。
- `#bDesign`：进入设计；本次进入时选中组装页。
- `#bReset`：恢复首页预制机；不会清除个人最佳。
- `#bNext`：设计底部「GAME START ▶」，直接开始飞行，不要求按设计标签顺序完成。
- `#bEdit`：结果页「設計しなおす」，回到设计。
- `#bAgain`：结果页「もう一度飛ぶ」，再次飞行。
- 游戏画布为 `canvas#cv`。编辑页有放大、缩小、适合视图按钮（`#zin`、`#zout`、`#zfit`）。
- 顶层「全画面で遊ぶ」扩大 iframe，右上「全画面を終了」退出。
- 顶层在飞行结束后会弹出成绩分享遮罩。遮罩覆盖 iframe 时，画布鼠标操作不会生效；其「もう一回」按钮为 `button[data-sheet="retry"]`，点击会重新加载游戏 iframe。E03 保留了这个失败案例；重试 E03b 先消除遮罩，再操作。

截图：[重载后的首页](evidence/10-initial-after-reload.png)、[最终恢复默认首页](evidence/19-final-reset-home.png)。

## 2. 八个设计标签：单位、默认值与交互

以下默认值均来自首页重置后的可见读数。

### 骨格（骨架）

**Observed**：侧视，端点方形手柄调整长度；说明指出尾翼跟随后端。清除后可横向画线重建。

- 长度 6.65 m；骨架质量 3.66 kg。
- 全备重量 85.0 kg；机体重量 25.0 kg。
- 重心 x = -0.036 m；重心 z = -0.119 m。
- 「ガイドどおり」与首页重置不同：本次先清空骨架，再点引导，得到长度 **7.85 m**、质量 **4.32 kg**、全备重量 85.6 kg。不能把引导按钮理解为恢复首页默认。
- **Unknown**：骨架长度上下界、拖动最小步长、线段倾斜时的约束。

截图：[默认骨架](evidence/default-skeleton.png)、[清空骨架](evidence/17-skeleton-cleared.png)。

### パイロット（驾驶员）

**Observed**：60 kg，俯卧；默认身体位置 x = 0.15 m。沿骨架拖动位置，驾驶舱随驾驶员移动。

- 正式实验后移至 x = -0.70 m；前移至 x = 0.40 m。
- 拖动反馈出现「骨格に吸い付く」（吸附骨架），失败的小范围尝试出现「標準の位置」（标准位置）。
- 质量不是可见输入控件。
- **Unknown**：位置绝对上下界、吸附容差与精确步长。

截图：[默认驾驶员](evidence/default-pilot.png)、[前移成功](evidence/E04c-design.png)、[后移成功](evidence/E05-design.png)。

### コックピット（驾驶舱）

**Observed**：侧视，方形手柄调形；清除后可一笔重画。说明明确指出，减小驾驶舱会减阻，但也减少体重移动空间。

- 长×高 2.45×0.70 m。
- 前面面积 0.316 m²；阻力 CdA 0.031 m²。
- 身体露出 0%；体重移动余量 ±25 cm。
- 驾驶舱质量 10.0 kg。
- 本调查的成功前后移通过驾驶员页完成，驾驶舱随动；不是已证实的“只移动驾驶舱、不移动驾驶员”的独立实验。
- **Unknown**：各顶点边界、最小合法尺寸、独立驾驶舱平移的精确命中区域、露出率和阻力计算公式。

截图：[默认驾驶舱](evidence/default-cockpit.png)。

### 主翼

**Observed**：俯视，四个方形角点调台形，内部拖动前后平移；清除后以四边形重画，左翼自动对称。

- 翼展 b = 14.00 m；面积 S = 18.20 m²。

- **Unknown**：翼展/弦长/平移上下界、交叉四边形的处理、质量与空气动力公式。

### 組み立て（组装）

**Observed**：侧视，各部件沿骨架拖动；主翼还能上下移动。图中 ◐ 表示重心、△ 表示气动中心；说明要求重心处于气动中心前方斜线区。

| 原生控件 | 含义 | 单位 | 最小 | 最大 | 步长 | 首页重置默认 |
|---|---|---|---:|---:|---:|---:|
| `input#slW` | 主翼安装角 | ° | -4 | 12 | 0.1 | 4 |
| `input#slT` | 尾翼安装角 | ° | -12 | 12 | 0.1 | 6 |

以上 min/max/step/value 是可见原生控件的 DOM 属性，未读取源码。

默认诊断：全备重量 85.0 kg；重心 45.1 %MAC；重心与气动中心差 3.7 %MAC；巡航速度 7.95 m/s；空中滑翔比 20.2；水面 1m 滑翔比显示破折号；下沉率 0.39 m/s；主翼 CL = 1.18；Cnβ = 0.0312；Clβ = -0.1421；螺旋状态「発散(ゆっくり)」（缓慢发散）。安装角警告为抬头过强、会失速，建议降低主翼安装角。

**Unknown**：斜线稳定区的精确端点、诊断阈值、自动配平算法、各部件位置极限。

## 3. 飞行和飞控

**Observed**：起飞先有助跑动画。画布说明为“翼持人员推着加速（10m、3.5°）”。助跑时飞行时间显示 t = 0.00 s。空中采用侧视主画面，右上有后视和俯视小窗、速度倍率按钮。

- 左半屏按住：身体后移，抬头。
- 右半屏按住：身体前移，低头。
- 左下与右下「ラダー」按钮：方向舵左/右。
- 体重移动条显示位移 cm 和重心变化 cm。

- 右方向舵长按实测 **R15°**；后视小窗显示倾斜，俯视显示航迹与横向偏移。
- 点击右上倍率，已观测 **×1 切到 ×2**。其他倍率及循环顺序为 **Unknown**。
- 助跑阶段按左侧和方向舵，本次没有看到位移/方向舵输入改变；该次结果仍为 84.88m。不能据此断言所有助跑输入规则。

## 5. 保存、重置与引导

### 自动保存（Observed）

1. 默认组装页将主翼安装角改为7.3°，尾翼仍6°。
2. 重载顶层页面，首页保留最佳115.27m。
3. 点击设计后，主翼仍7.3°。界面没有另行点击“保存”。
4. 点击首页重置，再进入设计，主翼恢复4°、尾翼6°、全备重量85.0kg、重心45.1%MAC。
5. 重置后的首页仍保留最佳115.27m。

这证明本次浏览器中设计与最佳成绩跨重载保留，并且首页重置不清最佳。**Unknown**：存储键名、版本迁移、损坏恢复策略、跨浏览器同步、所有几何字段是否逐项持久化。未读取存储内容来反推实现。

### 清空与引导（Observed）

- 骨架清空后，尺寸/重量诊断从面板消失，重画和引导按钮仍存在。
- 引导重建的骨架是7.85m，不是首页预制机6.65m。
- 组装辅助配平同时改变位置与安装角，显示“把重心放入斜线范围、主翼安装角匹配巡航”的操作反馈。
- **Unknown**：没有骨架时点击起飞的处理、所有缺部件组合的校验规则，以及其他部件引导是否等同默认几何。

调查结束已点击首页重置，将共享浏览器中的机体恢复预制默认。最佳115.27m按原版规则保留。
