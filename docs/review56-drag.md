# PR #56：飞行与风洞一致性及阻力核查

对应 [review 5875614273](https://github.com/Nigh/glider-3d/pull/56#pullrequestreview-5875614273)。原始测试机保存为 [review56-twin.json](../tests/fixtures/review56-twin.json)，来源为 review 附件，未调整其安装角、材料或发动机参数。

## 角度与力矩差异

该机主翼安装角为 **4°**。旧界面“攻角”显示的是机身迎角加主翼安装角；风洞“俯仰角度”控制机身姿态。因此飞行读数5.3°与风洞仰角5.3°不是同一工况：水平航迹、零滚转时，前者的机身迎角约1.3°，后者的主翼几何迎角约9.3°。有效翼段迎角还包含后掠、弹性与异翼尾迹，不能与这两个角互换。

在旧版本 `ea19765`、31 m/s、零杆量下复现：

| 工况 | 机身迎角 | 主翼几何迎角 | 总阻力 N | 非诱导 N | 诱导 N | 俯仰力矩 N·m |
|---|---:|---:|---:|---:|---:|---:|
| 海平面满油受力参考，80%油门 | 1.3° | 5.3° | 409.00 | 268.91 | 140.09 | +0.39 |
| 无动力风洞，稳定25 s | 1.3° | 5.3° | 409.09 | 268.90 | 140.19 | −118.88 |
| 无动力风洞，稳定25 s | 5.3° | 9.3° | 506.86 | 302.52 | 204.34 | −785.07 |

最后一行复现了 review 的风洞观察。第一行是明确输入下的受力探针，不是用户那次飞行的完整状态，不能将其409 N冒充对约423 N飞行读数的逐帧复现。其速度、油量、轨迹角、舵面状态和弹性形状须由同一录像确定。

1.3°的力矩差异主要是发动机推力：两台发动机位于重心下方，约432 N推力产生约+119 N·m抬头矩；无动力风洞没有该项。风洞仍应显示真实的未配平气动力矩。非线性弹性形状、地效和支架约束也可产生差异，尤其在较大迎角时。

新增回归把两种模式的几何、来流、姿态、角速度、地效和舵量完全一致地冻结，验证阻力与无动力力矩一致至1e−10；单独开启发动机后，阻力不变，新增力矩等于挂点推力矩。没有增加模式专用修正系数。

现在中英日界面分别显示“机身攻角”“主翼几何攻角”“主翼有效攻角”，并说明风洞无动力、仰角不含安装角。内部 `telemetry.alpha` 保留原有主翼几何迎角含义，未改变操纵或失速判据；`aerodynamics.alpha` 是机身来流迎角。

## 高雷诺数范围

实际计算使用每段未扰动局部速度与弦长：`Re = |v + ω×r| × chord / 1.46e−5`。31 m/s、零角速度下：

| 翼面 | 局部弦长 m | Re范围 |
|---|---:|---:|
| 主翼 | 1.7705–3.6839 | 3.7593M–7.8220M |
| 副翼 | 0.5123–0.7366 | 1.0877M–1.5640M |
| 垂尾 | 0.4331–0.6757 | 0.9196M–1.4346M |

确实超出了当前数据。核对 [AirfoilTools DAE-11页面](http://airfoiltools.com/airfoil/details?airfoil=dae11-il)及其 [1M原始CSV](http://airfoiltools.com/polar/csv?polar=xf-dae11-il-1000000)：当前采用的XFOIL6.96、Mach0、Ncrit9数据最高为1M，不能把1M结果声称为8M预测。模型对更高Re仍沿用1M边界；例如α=0°的翼型型阻CD在1M/8M都为0.00773。没有外推一个未经验证的下降曲线。

这可能带来物理偏差，但不会造成同一状态下的模式差异，因为飞行与风洞调用同一个极曲线函数。现有数据不足以定量证明8M时应降低多少；需要相同翼型、转捩/粗糙度条件下的高Re极曲线或实验。界面新增真实局部Re范围，并明确标示超出极曲线范围。低于200k的既有外推限制也仍存在。

## 非诱导阻力与可确认修正

测试机主翼面积8.112 m²，31 m/s、ρ=1.225 kg/m³时 `qS = 4774.8246 N`。修正后1.3°无动力风洞的模型分项：

| 实际计算项 | N | 除以qS的系数贡献 |
|---|---:|---:|
| 翼型型阻，包含摩擦与压差 | 55.3323 | 0.01159 |
| 翼面分离阻力 | 0.0716 | 0.00001 |
| 展向来流工程代理 | 34.1906 | 0.00716 |
| 座舱/罩体压差代理 | 93.4750 | 0.01958 |
| 座舱/罩体表面摩擦 | 20.2786 | 0.00425 |
| 未解析机体，0.07 m²等效面积 | 41.2029 | 0.00863 |
| 发动机外阻 | 15.9473 | 0.00334 |
| 发动机支架 | 4.0479 | 0.00085 |
| 水阻 | 0 | 0 |
| **非诱导合计** | **264.5461** | **0.05540** |
| 诱导合计 | 140.1908 | 0.02936 |
| **总阻力** | **404.7369** | **0.08476** |

非诱导系数依然较高，不能把它称为已标定的真实整机CD₀。它不是单独的表面摩擦，也不是在严格零升力状态测得的系数。座舱/未解析机体/发动机共174.95 N，占非诱导约66.1%；仅延长翼型Re数据不能自动解决这些项。翼型型阻还包含压差，例如1M、α=0°的原始CSV给出CD=0.00773、CDp=0.00203；不能只保留两者之差来替代总型阻。

确认并修正的缺陷是**椭球湿表面积**。旧 `2πa(b+c)`不是一般椭球的表面积；对于当前壳体和罩体均偏大。改为对实际半轴进行16点Gauss–Legendre×32方位积分：`S = abc ∫sqrt(nx²/a² + ny²/b² + nz²/c²) dΩ`。球体恢复4πr²，长旋转椭球与解析式误差小于0.05%；公式背景见[椭球表面积](https://mathworld.wolfram.com/Ellipsoid.html)。摩擦系数0.004和罩体露出比例0.5保持原值。

| 几何代理 | 旧面积 m² | 椭球面积 m² |
|---|---:|---:|
| 座舱壳体 | 7.83513 | 6.37598 |
| 完整罩体，施力时仍乘露出比例0.5 | 5.25651 | 4.47377 |

该修正使31 m/s下的机体摩擦降低约4.357 N；1.3°风洞非诱导从268.903降到264.546 N，总阻力从409.094降到404.737 N。没有统一降低所有阻力。

**仍未标定的部分：**座舱压差系数0.18、未解析机体面积0.07 m²、展向来流代理CD=0.012及其低Re缩放、罩体露出近似、对称垂尾代理、低展弦比/大后掠的三维效应和Re>1M翼型数据。这些项可能有较大的模型偏差；缺少同构型实测，无法确认可靠的进一步调参方案，本次不将其宣称为现实校准。

## 显示、守恒与复现

飞行中仅显示“非诱导阻力”和“诱导阻力”；风洞显示上表的实际计算项，零值也保留。翼型总型阻没有被虚构地拆成独立摩擦和压差两项；机体两项则来自它们各自实际的计算。分离、展向、发动机支架和接水项分别记账。

所有分项向量与总阻力闭合。显示统一为沿未扰动来流方向的有符号投影，分项可相加；有角速度或不同局部来流时不再分别取向量长度。无来流时用机头轴作为共同参考。水阻包含翼面与此前显示汇总遗漏的机身水阻；没有重复施力或修改耗散账本。
